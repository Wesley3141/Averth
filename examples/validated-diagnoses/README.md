# Validated diagnoses

A curated copy of the clean-run Averth diagnoses behind the 40-POC
outreach-ready index: `40-poc-outreach-ready-index.md` plus the 43
counted A-lane POC files (batches 1–5), copied verbatim, including
their wave-5 and wave-5b addenda. Where an addendum supersedes a filed
total, the addendum total governs; see the index's corrections log.

## Read this first — what these files are not

- Every dollar is estimated unless the lane used recorded tokens.
  No total in this folder is a bill, a vendor invoice, or a saving.
- No change was tested and no saving was measured. Every lane here
  is a clean-run diagnosis only: no operator acted on a finding.
- No lane has a verified individual recipient. Dataset teams and
  dataset author handles named in these files are data sources, not
  verified outreach recipients.
- Nothing in this folder is a send draft, and nothing here
  authorizes a send.

## What was deliberately left out

- Raw trajectories and events files (`.jsonl`, `.html` reports):
  not included; the POC markdowns summarize the runs.
- B lanes (clean runs on biased samples: lanes 26, 30, 32, 33, 45)
  and FAIL lanes (no usable trace, no labels, or aggregate-only):
  not counted, not included.
- Batch-1 reference files (POC 04, POC 08, POC 09): demos or single
  traces, not outreach POCs; not included.
- Prospect-derived material: none. These diagnoses come from public
  traces and datasets, not from any prospect's shared materials.
